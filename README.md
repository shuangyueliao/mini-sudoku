# Mini Sudoku

Free single-file HTML5 sudoku. Three grid sizes (4×4, 6×6, 9×9) and three
difficulties — every puzzle is generated on the fly with a guaranteed unique
solution. Pencil notes, mistake tracking, timer, per-mode best times.

**Play:** https://shuangyueliao.github.io/mini-sudoku/

- Mouse / touch / full keyboard (1-9 type, arrows move, Backspace erase, N notes, M mute)
- Backtracking generator with solution-counter pruning (stops counting at 2) — 9×9 Hard in ~10 ms
- Canvas board, WebAudio sounds, single HTML file, zero external assets, no tracking
